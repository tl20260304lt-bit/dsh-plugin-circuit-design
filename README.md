# dsh-plugin-circuit-design

Circuit design and PCB layout workflow skill for DeepSeek Harness.

## Skills

- **circuit-design**: Hardware design workflow covering schematic capture, PCB layout, BOM management, and design review

## Installation

```bash
dsh install github:tl20260304lt-bit/dsh-plugin-circuit-design
```

## Usage

After installation, the `circuit-design` skill is available in DSH. Use it when:

- Starting a new circuit/PCB project
- Checking schematic or PCB design integrity
- Validating BOM before fabrication
- Preparing Gerber files for manufacturing
