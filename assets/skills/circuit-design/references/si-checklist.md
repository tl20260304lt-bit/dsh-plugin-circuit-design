# 信号完整性 (SI) 检查清单

## 传输线设计

### 阻抗控制

- [ ] 识别所有需要阻抗控制的网络（时钟、差分对、高速串行）
- [ ] 计算微带/带状线线宽（使用 Polar SI9000 或 KiCad PCB Calculator）
- [ ] 设置 DRC 规则：阻抗容差 ±10%
- [ ] 确认板厂能做到的阻抗精度（通常 ±10% 到 ±15%）

| 信号类型 | 目标阻抗 | 容差 |
|---------|---------|------|
| USB 2.0 | 90Ω 差分 | ±15% |
| USB 3.0 | 90Ω 差分 | ±10% |
| Ethernet RMII | 100Ω 差分 | ±10% |
| DDR3/4 数据 | 40Ω 单端 (80Ω ODT) | ±10% |
| PCIe | 100Ω 差分 | ±10% |

### 走线规则

- [ ] 3W 规则：中心线间距 ≥ 3×线宽（减少串扰）
- [ ] 20H 规则：电源/地平面扩展 ≥ 20×层间距（减少边缘辐射）
- [ ] 时钟信号包地（两侧或底部铺地）
- [ ] 避免跨分割（信号返回路径不中断）

## 时钟设计

- [ ] 时钟源靠近接收端
- [ ] 时钟线不与其它信号同层平行（避免串扰）
- [ ] 必要时使用端接电阻（串联或并联）
- [ ] 有源晶振输出直接到负载，不加电阻

## 差分对

- [ ] 等长：长度差 ≤ 信号上升时间的 1/10 对应电长度
- [ ] 耦合：保持恒定间距（不跨器件、不过孔错位）
- [ ] 端接：源端或远端端接（根据协议）
- [ ] 过孔：尽量少的过孔，使用背钻减少残桩

## DDR 内存

- [ ] 飞线长度匹配（按组）
- [ ] 拓扑：T-topology 或 fly-by（根据速度）
- [ ] 电源去耦：每个 VDD/VSS 引脚对放置 0.1µF + 0.01µF
- [ ] 等长：DQ 组内 ±5mil，DQS 与 DQ 中心对齐

## 串扰控制

- [ ] 敏感信号（时钟、复位）远离高速数据线
- [ ] 平行走线长度 ≤ 5mm（如果无法避免）
- [ ] 层叠：信号层紧贴参考平面
- [ ] 关键信号走内层（带状线，屏蔽更好）

## 端接

| 场景 | 端接方式 |
|------|---------|
| 点 - 多点时钟 | 并联 RC 或并联电阻 |
| 点对点高速 | 源端串联电阻 |
| 差分对 | 远端 100Ω 并联 |
| DDR | ODT (On-Die Termination) |

## 过孔

- [ ] 使用背钻（via stub）如果信号 > 1Gbps
- [ ] 过孔反铺地（via stitching）保持返回路径
- [ ] BGA 扇出使用 micro-via 或 tent + solder mask
